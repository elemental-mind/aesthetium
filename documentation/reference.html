Frequently Asked Questions

Do I need JavaScript to use Aesthetium?

No. Aesthetium is a pure CSS framework with zero JavaScript dependencies. Everything works with just HTML and CSS.

How do I customize the theme?

Override any CSS custom property in your own stylesheet. Change --color-accent for brand color, --font-body for typography, and so on.

Is dark mode supported?

Yes, dark mode is built-in and activates automatically based on the user's system preference via prefers-color-scheme.

What's the bundle size?

Under 5KB gzipped. The framework is built with PostCSS and optimized with cssnano for minimal footprint.
