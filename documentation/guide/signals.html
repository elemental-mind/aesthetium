Signals

Signal attributes communicate state or tone: positive, negative, alert, or inactive. They stay small so they can be combined with components and layout attributes.

Status Tone

Use tone attributes directly on the element that carries the meaning.

<p positive>Saved successfully.</p>
<p negative>Payment failed.</p>
<p alert>Storage almost full.</p>

Saved successfully.

Payment failed.

Inactive State

[inactive] lowers opacity for unavailable, disabled-looking, or secondary content. It does not change actual HTML behavior, so keep using native attributes like disabled when interaction must be blocked.

<button inactive>Unavailable</button>
<button disabled>Disabled</button>

Attributes

AttributeEffect
[positive]Uses the positive color token for success or confirmation.
[negative]Uses the negative color token for errors or destructive meaning.
[alert]Uses the alert color token for warnings or attention.
[inactive]Reduces opacity to show lowered availability or emphasis.

Parent Child Signals

[items-inactive] dims every direct child. A child can still add meaning with [positive], [negative], or [alert]; those attributes change color while the parent still supplies the inactive opacity.

<div stack items-inactive>
  <p>Dimmed by parent</p>
  <p positive>Positive, but still inactive</p>
  <p alert>Alert, but still inactive</p>
</div>
