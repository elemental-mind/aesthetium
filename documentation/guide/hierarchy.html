Hierarchy

Hierarchy attributes adjust visual importance through color, weight, and emphasis. They are useful for labels, metadata, navigation groups, and repeated content.

Single Element Hierarchy

Apply hierarchy directly when one element needs to stand apart.

<p highlight>Primary text</p>
<p light>Muted text</p>
<p heavy>Heavy text</p>
<p emphasized>Emphasized text</p>

Attributes

AttributeEffect
[highlight]Uses the primary color token.
[light]Uses the muted color token.
[heavy]Sets a heavy font weight.
[emphasized]Sets italic emphasis.
[plain]Returns color and weight to inherited values and removes italic style.

Parent Child Hierarchy

Use items- attributes on a parent to style every direct child. Then place a plain attribute on a child when that one member needs to opt out or take a different role.

<nav strip items-highlighted>
  <a href="/">Home</a>
  <a href="/docs" plain>Docs</a>
  <a href="/account" light>Account</a>
</nav>
Home Docs Account

Item Attributes

Parent AttributeDirect Child EffectUseful Override
[items-highlighted]Every direct child uses the primary color.[plain] or [light]
[items-light]Every direct child uses the muted color.[plain] or [highlight]
[items-heavy]Every direct child receives heavy font weight.[plain]
[items-emphasized]Every direct child becomes italic.[plain]

Combining Parent Rules

Parent attributes compose. This example makes all children highlighted and heavy, while one child opts out with [plain] and another switches to muted text.

<div stack items-highlighted items-heavy>
  <p>Important item</p>
  <p plain>Plain child override</p>
  <p light>Muted child override</p>
</div>
