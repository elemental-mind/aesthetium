Layout

Aesthetium provides structural layout through boolean HTML attributes. Layout attributes describe how an element arranges its direct children.

They can be mixed with spacing attributes and with child-item attributes from the depth, signals, and hierarchy guides.

Flex Composition

Use these when each child should keep its natural or component-defined size.

[strip]

Horizontal flex container with centered children and a default gap.

<div strip>
  <article>One</article>
  <article>Two</article>
  <article>Three</article>
</div>

[stack]

Vertical flex container with a default gap.

  <p>First</p>
  <p>Second</p>
  <p>Third</p>

[strips] / [stacks]

Wrapping flex containers. [strips] wraps horizontal rows; [stacks] wraps vertical columns when the height is constrained.

<div strips>
  <article>One</article>
  <article>Two</article>
  <article>Three</article>
</div>

[spread] / [centered]

[spread] distributes children with justify-content: space-between. [centered] centers children on both axes.

<div strip spread>
  <strong>Brand</strong>
  <span badge>Right-aligned</span>
</div>
Brand Right-aligned

Grid Composition

Use tile attributes when children should share predictable grid tracks.

[tiles]

Responsive grid whose columns fit the available width. Change the minimum tile size with --tile-min.

<div tiles style="--tile-min: 10rem">
  <article>Alpha</article>
  <article>Beta</article>
  <article>Gamma</article>
</div>

[tile-strip] / [tile-stack]

Equal-track grids in one direction. Add [scrollable] when the track list can overflow.

<div tile-strip scrollable>
  <article>One</article>
  <article>Two</article>
  <article>Three</article>
</div>

[compact] / [spacious]

Tighten or loosen the default gap on layout containers.

<div strip compact>...</div>
<div strip spacious>...</div>
Compact Gap Items
Spacious Gap Items

[scrollable]

Adds internal scrolling to supported layout containers. On [strip] and [tile-strip] it scrolls horizontally; on [stack] and [tile-stack] it scrolls vertically.

<div strip scrollable>...wide content...</div>
<div stack scrollable>...tall content...</div>

Sidebar Pattern

A two-column layout with a main content area and a narrower aside:

<section strips>
  <div stack>
    <h2>Main content</h2>
    <p>...</p>
  </div>
  <aside>
    <strong>Sidebar</strong>
    <p>...</p>
  </aside>
</section>

Main content

The main column grows to fill available space.

Sidebar

The aside keeps a stable sidebar width.

Parent And Child Attributes

Layout attributes set container behavior. Other attribute groups can style the children from the parent, then a child can opt out or override itself with a plain attribute.

<div tiles items-highlighted items-raised>
  <article>Highlighted and raised</article>
  <article plain flat>Plain and flat</article>
  <article>Highlighted and raised</article>
</div>
