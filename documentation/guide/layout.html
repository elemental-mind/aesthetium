Layout

Aesthetium provides structural layout through boolean HTML attributes. No utility classes — just intent expressed directly in markup.

[row]

Horizontal flex container with a default gap.

<div row>
  <article>One</article>
  <article>Two</article>
  <article>Three</article>
</div>
One
Two
Three

[stack]

Vertical flex container with a default gap.

<div stack>
  <p>First</p>
  <p>Second</p>
  <p>Third</p>
</div>
First
Second
Third

[spread]

Distributes children with justify-content: space-between. Usually combined with [row].

<div row spread>
  <strong>Brand</strong>
  <nav>…</nav>
</div>
Brand Right-aligned

[centered]

Centers children both horizontally and vertically.

<section centered>
  <h2>Centered content</h2>
  <p>All children are centered.</p>
</section>

Centered content

All children are centered.

[wrap]

Enables flex wrapping. Combine with [row] for responsive grids.

<div row wrap>
  <article>…</article>
  <article>…</article>
  <article>…</article>
</div>

[compact] / [spacious]

Tighten or loosen the default gap on any flex container.

<div row compact>…</div>
<div row spacious>…</div>
Compact Gap Items
Spacious Gap Items

[full-page]

Sets the element to min-height: 100svh. Ideal for hero sections.

<section full-page stack centered>
  <h1>Hero</h1>
</section>

[scrollable]

Constrains the element to a fixed height with internal scroll.

<div scrollable>…long content…</div>

[inverted]

Forces the dark-mode palette on any element, regardless of OS setting.

<section inverted stack centered>
  <h2>Dark section</h2>
  <p>Always renders in the dark palette.</p>
  <button highlight>CTA</button>
</section>

Dark section

Page Structure

A typical Aesthetium page uses semantic elements that are automatically styled:

<body>
  <header>…nav…</header>

  <main>
    <section>…hero…</section>
    <section>…content…</section>
  </main>

  <footer>…links…</footer>
</body>
  • header — sticky top nav, flex spread by default
  • main — centered container with --container-width
  • section — padded content block
  • footer — padded bottom section with muted text
  • aside — callout / sidebar with border treatment

Sidebar Pattern

A two-column layout with a main content area and a narrower aside:

<section row wrap>
  <div stack>
    <h2>Main content</h2>
    <p>…</p>
  </div>
  <aside>
    <strong>Sidebar</strong>
    <p>…</p>
  </aside>
</section>

Main content

The main column grows to fill available space.

Sidebar

The aside shrinks to its natural width.
