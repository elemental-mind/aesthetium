Get Started

Aesthetium is a classless, attribute-driven CSS framework. Drop in one stylesheet and write semantic HTML — no class names, no JavaScript.

Installation

CDN

The fastest way to get started — no build step required.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/aesthetium/framework_distribution/aesthetium.css">

npm

npm install aesthetium

Then link from node_modules or import in your bundle entry:

import 'aesthetium/framework_distribution/aesthetium.css';

Bundler (Vite / webpack)

If your bundler resolves the style field in package.json, a bare import is enough:

import 'aesthetium';

Quick Start

Create an HTML file, link the stylesheet, and write semantic markup:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <link rel="stylesheet" href="aesthetium.css">
</head>
<body>
  <header>
    <strong>My App</strong>
    <nav>
      <a href="/">Home</a>
      <a href="/about">About</a>
    </nav>
  </header>

  <main>
    <section>
      <h1>Hello World</h1>
      <p>No classes needed.</p>
      <button highlight>Get Started</button>
      <button ghost>Learn More</button>
    </section>
  </main>
</body>
</html>

Core Concepts

Classless by default

Aesthetium targets semantic HTML elements directly — h1, button, table, form. You get styled output without adding a single class.

Attributes for variants

Boolean HTML attributes express intent without class names:

<button highlight>Primary action</button>
<button ghost>Secondary action</button>
<aside positive>Success message</aside>
<aside negative>Error message</aside>
<article inverted>Dark surface</article>

Token-based theming

The entire design system lives in CSS custom properties. Override them in your own :root block to apply your brand:

:root {
  --color-accent:    #6d28d9;
  --color-accent-fg: #ffffff;
  --font-body:       'Inter', sans-serif;
  --radius:          0.5rem;
}

Layout attributes

Structural layout is also attribute-driven:

<div row>…</div>           <!-- horizontal flex -->
<div stack>…</div>         <!-- vertical flex -->
<div row spread>…</div>    <!-- space-between -->
<section centered>…</section> <!-- centered content -->

Browser Support

Aesthetium uses CSS nesting and custom properties. These are supported in all modern browsers.

Browser Minimum version Status
Chrome / Edge 112+ Supported
Firefox 117+ Supported
Safari 16.5+ Supported
Internet Explorer All Not supported
