No class names

Aesthetium styles semantic HTML elements directly. Write <button>, get a beautiful button.

<button>Default</button>
<button highlight>Primary</button>
<button ghost>Secondary</button>

Attribute-driven variants

Boolean HTML attributes express intent — not appearance. Your markup stays readable and meaningful.

<aside positive>Saved!</aside>
<aside negative>Error</aside>
<aside alert>Warning</aside>
<article inverted>Dark card</article>

Error
Warning

Token-based theming

The entire design system is CSS custom properties. Override one token to change everything that references it.

:root {
  --color-accent: #6d28d9;
  --radius: 0.25rem;
  --font-body: 'Inter', sans-serif;
}
