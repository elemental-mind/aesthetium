# Aesthetium

# Colors
- Shades of gray as default
- Accent colors for positive/negative (green, red)
- Accent color for alert (yellow/orange)
- Customizable accent color for CTAs. By default black.

# Fonts
- Sleek modern Sans-Serif font.
- Separate customizable fonts for headers and other text

# Input Elements
- Slightly gray background by default. Should have a slight outline.

# Principles
- Classless.
- Attributes instead of classes. Attributes very seldomly used. Attributes really expressive. Not `<button class="cta">` but `<button cta>`
